# دفتر تغذیه (PWA)

اپ ساده برای ثبت غذای روزانه با متن فارسی و محاسبه کالری، پروتئین، کربوهیدرات، فیبر، قند و چربی — با امتیاز روزانه، هفتگی و ماهانه.

## ورودی
هر چی خوردی را با متن عادی بنویس:

```
۵ عدد سفیده تخم مرغ یک عدد زرده
یک اسکوپ وی
۸ قاشق برنج و ۲۰۰ گرم سینه مرغ
```

اعداد فارسی/انگلیسی، عددهای حروفی (یک، دو، یک و نیم، نصف…) و واحدهایی مثل گرم، عدد، قاشق، لیوان، کف دست، اسکوپ، سیخ، کفگیر و… را می‌فهمد. غذایی که در لیست نیست را می‌شود از خود اپ تعریف کرد.

## اهداف پیش‌فرض
| مورد | هدف |
|---|---|
| کالری | ۱۸۰۰ تا ۲۰۰۰ |
| پروتئین | ۱۸۰ گرم |
| کربوهیدرات | حداکثر ۵۰ گرم |
| فیبر | ۳۰ گرم |
| قند | صفر |
| چربی | ~۹۸ گرم (خودکار، برای بالانس ۱۸۰۰ کالری) |

امتیاز روز (۱۰۰): کالری ۲۵ + پروتئین ۳۰ + کربو ۱۵ + چربی ۱۰ + فیبر ۱۰ + قند ۱۰.

اهداف به هم وصل‌اند: همیشه کالری = ۴×پروتئین + ۴×کربو + ۹×چربی. ماشین‌حساب داخل اپ اهداف را بر اساس Mifflin-St Jeor / Katch-McArdle و توصیه‌های پروتئین برای حفظ عضله در کسری کالری پیشنهاد می‌دهد.

## نصب روی آیفون
1. در تنظیمات مخزن در GitHub: **Settings → Pages → Deploy from a branch** (همین شاخه، `/ (root)`).
2. آدرس سایت (مثل `https://<user>.github.io/Pwa-diet/`) را در **Safari** باز کن.
3. دکمه **Share** → **Add to Home Screen**.

اطلاعات فقط روی گوشی (localStorage) ذخیره می‌شود و اپ آفلاین هم کار می‌کند. از بخش تنظیمات فایل پشتیبان بگیر.
